ApPetito

Este proyecto es una app Android desarrollada como parte de una tarea de la universidad. La idea era construir algo funcional que simulara una app de comida, con navegación entre pantallas y manejo de datos básicos.

La app muestra una lista de restaurantes y, al entrar a cada uno, se puede ver su menú dividido en comida, bebidas y complementos. Cada producto tiene su propia vista de detalle con nombre, precio, imagen y una breve descripción.

Qué hace la app
Lista de restaurantes
Navegación a menú por restaurante
Separación por categorías (comida, bebidas, complementos)
Lista de productos por categoría
Pantalla de detalle por producto
Uso de colores dinámicos (Material You)
Uso de RecyclerView, Fragments y ViewPager2
Qué se aplicó
Navegación entre Activities
Uso de Intents para pasar datos
RecyclerView con adapters personalizados
Fragmentos para dividir contenido
ViewPager2 con TabLayout
Manejo básico de layouts con ConstraintLayout
Organización de recursos (drawables, layouts, etc.)
Uso de Material Components

Notas
No es una app pensada para producción ni conecta a ninguna base de datos. Todo el contenido está definido directamente en el código.
La intención principal fue practicar estructura, navegación y manejo de UI en Android.
