<h1>ApPetito</h1>

<p>
Este proyecto es una app Android desarrollada como parte de una tarea de la universidad.
La idea era construir algo funcional que simulara una app de comida, con navegación entre pantallas y manejo de datos básicos.
</p>

<p>
La app muestra una lista de restaurantes y, al entrar a cada uno, se puede ver su menú dividido en comida, bebidas y complementos.
Cada producto tiene su propia vista de detalle con nombre, precio, imagen y una breve descripción.
</p>

<h2>Qué hace la app</h2>

<ul>
    <li>Lista de restaurantes</li>
    <li>Navegación a menú por restaurante</li>
    <li>Separación por categorías (comida, bebidas, complementos)</li>
    <li>Lista de productos por categoría</li>
    <li>Pantalla de detalle por producto</li>
    <li>Uso de colores dinámicos (Material You)</li>
    <li>Uso de RecyclerView, Fragments y ViewPager2</li>
</ul>

<h2>Qué se aplicó</h2>

<ul>
    <li>Navegación entre Activities</li>
    <li>Uso de Intents para pasar datos</li>
    <li>RecyclerView con adapters personalizados</li>
    <li>Fragmentos para dividir contenido</li>
    <li>ViewPager2 con TabLayout</li>
    <li>Manejo básico de layouts con ConstraintLayout</li>
    <li>Organización de recursos (drawables, layouts, etc.)</li>
    <li>Uso de Material Components</li>
</ul>

<h2>Notas</h2>

<p>
No es una app pensada para producción ni conecta a ninguna base de datos.
Todo el contenido está definido directamente en el código.
</p>

<p>
La intención principal fue practicar estructura, navegación y manejo de UI en Android.
</p>
